# Lav Kush — Cloud & DevOps Aspirant Portfolio

An AI-assisted portfolio implementation of the responsive website described in my BCA project entry. It was prepared from that project brief; review and personalize it before presenting every implementation detail as independent hands-on work.

The static site uses HTML, CSS, and vanilla JavaScript to present coursework projects, current technical foundations, education, and contact links.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server. No package manager or build step is required.

## Features

- Responsive layout with mobile navigation
- Project, skills, and education sections
- Keyboard focus states, skip link, semantic landmarks, and reduced-motion support
- Client-side email validation for demonstration; submitted input is not transmitted or stored
- No backend, analytics, cookies, form-data storage, or personal email embedded in the site

## Deploy with GitHub Pages

1. Push this folder to a GitHub repository.
2. In repository settings, open **Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment to finish and use the published URL.
